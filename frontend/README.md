# Frontend планировщика

Одностраничное приложение на React и TypeScript. Работает с FastAPI через сессионную авторизацию; в production собранные файлы обслуживает backend.

## Разделы

- **Планирование** — задачи и назначения команд по датам, фильтры, статусы и зависимости.
- **Журнал** — история работ с фильтрацией по командам.
- **Статистика** — сводные показатели работы.
- **Настройки** — управление доступными пользователю справочниками и сущностями.
- **Отладка** — просмотр диагностической информации для пользователей с правами.

Интерфейс поддерживает светлую и тёмную темы, центр уведомлений, уведомления о просроченных назначениях и окно истории релизов.

## Разработка

Нужны Node.js и npm. Из корня проекта запустите backend:

```bash
python support_planner.py
```

В другом терминале:

```bash
cd frontend
npm ci
npm run dev
```

Vite проксирует API и авторизацию на `http://localhost:5093`. Для локального входа по умолчанию: `admin` / `q12345678`.

## Команды

```bash
npm test       # тесты Vitest и React Testing Library
npm run lint   # Oxlint
npm run build  # проверка TypeScript и production-сборка в dist/
```

Для проверки production-интеграции запускайте собранный frontend через backend на <http://127.0.0.1:5093>; `npm run preview` проверяет только Vite-сборку.

## Структура

- `src/pages/` — страницы планирования, журнала, статистики, настроек и отладки.
- `src/components/` — общие компоненты интерфейса.
- `src/hooks/` — загрузка данных и взаимодействие с API.
- `src/domain/` — типы предметной области; `src/lib/` — общие утилиты и ключи запросов.
- `src/theme.ts` — темы; `vite.config.ts` — dev-прокси и параметры сборки.
