# assignment-context-menu-presentation Specification

## Purpose

Определяет визуальное представление действий смены статуса назначения и приоритета работы в контекстных меню планирования.

## Requirements

### Requirement: Иконки действий смены статуса назначения
Система SHALL показывать семантическую иконку рядом с подписью каждого доступного действия смены статуса в контекстном меню назначения.

#### Scenario: Открытие контекстного меню редактируемого назначения
- **WHEN** пользователь открывает контекстное меню назначения, статус которого ему разрешено менять
- **THEN** каждый показанный пункт смены статуса содержит соответствующую статусу иконку и существующую текстовую подпись

#### Scenario: Выбор пункта с иконкой
- **WHEN** пользователь выбирает пункт смены статуса с иконкой
- **THEN** система выполняет тот же переход статуса, который был связан с этим пунктом до добавления иконки

### Requirement: Иконки изменения приоритета работы
Система SHALL показывать направленную иконку рядом с каждым доступным действием перемещения работы внутри уровня критичности.

#### Scenario: Открытие контекстного меню активной работы
- **WHEN** пользователь открывает контекстное меню работы, приоритет которой ему разрешено менять
- **THEN** пункт перемещения в начало содержит направленную вверх иконку, а пункт перемещения в конец — направленную вниз иконку

#### Scenario: Выбор действия изменения приоритета
- **WHEN** пользователь выбирает пункт изменения приоритета с иконкой
- **THEN** система выполняет то же перемещение работы, которое было связано с этим пунктом до добавления иконки
