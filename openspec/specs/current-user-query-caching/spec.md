# Кеширование query текущего пользователя

## Purpose

Определяет кратковременное переиспользование профиля текущего пользователя между потребителями React Query без немедленных повторных запросов `/api/me`.

## Requirements

### Requirement: Недавно полученный текущий пользователь переиспользуется

Frontend SHALL считать успешно полученный профиль текущего пользователя актуальным в течение 60 секунд и SHALL переиспользовать его между потребителями общего React Query query без немедленного повторного запроса.

#### Scenario: Вложенный потребитель монтируется после layout
- **WHEN** layout успешно получил `/api/me` и в течение 60 секунд монтируется вложенный компонент с тем же query key
- **THEN** вложенный компонент получает профиль из общего кэша без второго сетевого запроса `/api/me`

#### Scenario: Данные устарели
- **WHEN** после успешного `/api/me` прошло не менее 60 секунд и монтируется новый потребитель query
- **THEN** React Query может выполнить стандартное фоновое обновление профиля

### Requirement: Кеширование профиля не изменяет остальные queries

Настройка актуальности текущего пользователя MUST применяться только к `useMe` и MUST NOT изменять глобальные defaults QueryClient либо параметры других queries.

#### Scenario: Другой query монтирует нового потребителя
- **WHEN** компонент использует query, отличный от query текущего пользователя
- **THEN** для него сохраняются прежние глобальные настройки React Query
