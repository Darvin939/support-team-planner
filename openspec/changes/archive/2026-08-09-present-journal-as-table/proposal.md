## Why

Журнал изменений отображает структурированные записи в виде вертикального набора карточек, из-за чего время, работа, тип объекта, изменение и автор плохо сопоставляются между строками. Табличное представление сделает большой журнал компактнее и позволит быстрее просматривать историю команды.

## What Changes

- Унифицировать пагинацию на страницах планирования, статистики и журнала через общий компонент с одинаковыми стилем, размерами страниц и поведением.
- Закрепить заголовок таблицы журнала при вертикальной прокрутке, учитывая мобильную верхнюю панель.
- Представить историю выбранной работы в модальном окне журнала таблицей по паттерну «Архива работ», сохранив внешнюю серверную пагинацию.
- Заменить карточки журнала на таблицу Ant Design с колонками времени, работы, объекта, изменения и автора.
- Сохранить открытие истории работы по клику на строку.
- Показывать состояние загрузки и пустой результат средствами таблицы без дублирующего контейнера карточек.
- Сохранить существующие фильтры, серверный порядок записей и offset-пагинацию.
- Добавить адаптивное поведение таблицы для узких экранов с горизонтальной прокруткой и компактным набором колонок.

## Impact

- Frontend: `JournalPage`, `PlanningPage`, `StatisticsPage`, общий компонент пагинации, существующие history-formatters и UI-тесты затронутых страниц.
- Backend API, фильтрация, порядок данных и пагинация не меняются.
- Новые зависимости не требуются: используется установленный Ant Design Table.
