## Why

При загрузке защищённой страницы `AuthenticatedLayout` сначала получает `/api/me`, после чего вложенная страница монтирует второй observer того же React Query query и немедленно повторяет запрос, поскольку данные по умолчанию сразу считаются устаревшими. Профиль и роль не меняются в пределах обычной навигации, поэтому этот повторный запрос не приносит новых данных.

## What Changes

- Задать ограниченный `staleTime` непосредственно для query текущего пользователя `useMe`.
- Сохранить единый query key и совместное использование кэша всеми потребителями `useMe`.
- Не менять глобальные настройки React Query и поведение остальных запросов.
- Добавить проверку конфигурации/поведения, исключающую немедленный повторный `/api/me` при последовательном монтировании потребителей.
