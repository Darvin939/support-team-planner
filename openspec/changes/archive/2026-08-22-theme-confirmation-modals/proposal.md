## Why

Статические окна `Modal.confirm` создаются вне контекста тематического `ConfigProvider`, поэтому в тёмной теме сохраняют светлый фон и светлую цветовую схему. Подтверждения должны визуально соответствовать текущей теме так же, как остальные модальные окна приложения.

## What Changes

- Подключить контекстный API Ant Design для программно создаваемых модальных окон внутри активной темы приложения.
- Перевести подтверждения изменения статуса работы и признака ПСИ на тематический modal API.
- Добавить component-тесты светлой и тёмной темы для программного окна подтверждения.
- Проверить реальное отображение подтверждения в production-интерфейсе в обеих темах.

## Capabilities

### New Capabilities

- `themed-confirmation-modals`: соответствие программных окон подтверждения активной теме приложения.

## Impact

Изменения затронут корневую композицию React/Ant Design, `AssignmentModal`, контекстное меню работ и связанные frontend-тесты. Backend API и схема БД не меняются.
