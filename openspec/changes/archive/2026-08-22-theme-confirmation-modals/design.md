## Context

Приложение переключает алгоритм темы через `ConfigProvider`, однако подтверждения вызываются статическим `Modal.confirm`. Статический API создаёт отдельное React-дерево и не получает актуальный контекст темы, локали и токенов. Проблема затрагивает подтверждение перевода назначения в выполненное и действия ПСИ из контекстного меню работы.

## Goals / Non-Goals

**Goals:**

- Рендерить все программные подтверждения внутри актуального Ant Design context.
- Сохранить тексты, обработчики подтверждения/отмены и бизнес-логику существующих действий.
- Покрыть контекстный механизм component-тестом и визуально проверить тёмную тему.

**Non-Goals:**

- Изменение дизайна обычных декларативных `Modal`.
- Изменение бизнес-правил статусов назначений или ПСИ.
- Собственная реализация диалогов вместо Ant Design.

## Decisions

Корень приложения SHALL содержать Ant Design `App` внутри тематического `ConfigProvider`. Компоненты, создающие подтверждения, SHALL получать `modal` через `App.useApp()` и вызывать `modal.confirm`. Это официальный контекстный API и позволяет наследовать тему без ручного копирования токенов или CSS-переопределений.

Прямое стилистическое переопределение `.ant-modal-confirm` не используется: оно дублировало бы систему токенов и могло расходиться со светлой темой. Передача темы в каждый вызов также не используется, поскольку оставляет риск новых нетематических подтверждений.

Тесты SHALL проверять использование контекстного modal API и сохранение callback-поведения. Production Playwright SHALL открыть реальное подтверждение после переключения темы и проверить вычисленные цвета/визуальный результат.

## Risks / Trade-offs

- [Имя `App` конфликтует с корневым компонентом приложения] → импортировать Ant Design компонент с псевдонимом либо переименовать локальный корневой компонент.
- [Контекстный API требует наличия holder выше всех потребителей] → разместить Ant Design `App` непосредственно под `ConfigProvider` и над router/query tree.
- [Тестовые моки статического `Modal.confirm` перестанут работать] → обновить тестовые обёртки и моки на `App.useApp()` без изменения проверяемой бизнес-логики.
