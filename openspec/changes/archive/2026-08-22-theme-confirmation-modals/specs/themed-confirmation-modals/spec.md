## ADDED Requirements

### Requirement: Программные подтверждения наследуют активную тему
Frontend SHALL создавать программные окна подтверждения через контекстный Ant Design modal API внутри активного тематического provider.

#### Scenario: Подтверждение в тёмной теме
- **WHEN** пользователь открывает программное подтверждение при включённой тёмной теме
- **THEN** фон, текст, границы, иконка и кнопки окна используют токены тёмной темы

#### Scenario: Подтверждение в светлой теме
- **WHEN** пользователь открывает программное подтверждение при включённой светлой теме
- **THEN** окно использует токены светлой темы без отдельных CSS-переопределений

### Requirement: Тематизация не изменяет поведение подтверждения
Переход на контекстный modal API SHALL сохранять существующие тексты, варианты кнопок и обработчики подтверждения и отмены.

#### Scenario: Пользователь подтверждает действие
- **WHEN** пользователь нажимает основную кнопку программного подтверждения
- **THEN** выполняется тот же доменный обработчик, который был связан с действием до изменения тематизации

#### Scenario: Пользователь отменяет действие
- **WHEN** пользователь закрывает окно или нажимает кнопку отмены
- **THEN** доменное изменение не выполняется
