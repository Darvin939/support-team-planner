## Why

Период планировщика ограничивает видимые даты и не позволяет быстро увидеть полную историю назначений конкретной работы. Единый таймлайн в карточке любой работы даст эту историю независимо от выбранного периода, а архив сохранит тот же прозрачный просмотр назначений всех статусов.

## What Changes

- Показывать таймлайн назначений в основной вкладке карточки работы для всех существующих работ, включая активные.
- Сохранять представление всей истории назначений в архиве, включая все статусы; переиспользовать существующий API и компонент таймлайна.
- Не менять API: он уже возвращает все неудалённые назначения всех статусов.

### Modified Capabilities
- `planning-table-structure`: таймлайн назначений должен быть доступен в карточке для работ любого статуса; архивный таймлайн показывает полный набор неудалённых назначений всех статусов.

## Impact

- Frontend: `TaskModal`, `TaskArchiveModal` и общий `AssignmentTimeline`.
- Backend API и схема БД не меняются; существующий защищённый endpoint таймлайна уже возвращает нужные данные.
