## Why

Пункты смены статуса назначения и изменения приоритета работы в контекстных меню сейчас различаются только текстом, из-за чего меню медленнее считываются визуально. Семантические иконки сделают доступные действия заметнее и обеспечат единообразное представление действий планирования.

## What Changes

- Добавить каждому пункту смены статуса назначения подходящую иконку Ant Design.
- Добавить иконки пунктам перемещения работы в начало и конец уровня критичности.
- Сохранить существующие подписи и обработчики действий без функциональных изменений.
- Проверить отображение иконок в production UI для обоих контекстных меню.

## Capabilities

### New Capabilities

- `assignment-context-menu-presentation`: визуальное представление действий смены статуса назначения и приоритета работы в контекстных меню планирования.

### Modified Capabilities

Нет.

## Impact

- Frontend: `frontend/src/pages/planning/usePlanningColumns.tsx`.
- Используются иконки из уже подключённого пакета `@ant-design/icons`; новые зависимости и изменения API не требуются.
- Поведение смены статуса назначения, изменения приоритета работы и права доступа не меняются.
