## Context

Календарь статистики уже показывает дату и точный счётчик в одной ячейке. Два числа визуально равноправны, из-за чего счётчик можно принять за часть даты. Изменение затрагивает только React-компонент и его CSS; структура данных и API остаются прежними.

## Goals / Non-Goals

**Goals:**
- Ясно различать дату и количество активных работ.
- Сохранить компоновку календаря на узких экранах.

**Non-Goals:**
- Менять фильтрацию, подсчёт или выбор дат.
- Менять API и детали выбранного дня.

## Decisions

- Оставить дату основным текстом ячейки, положительный счётчик оформить компактным бейджем с числом и правильной формой слова «работ»; при нуле бейдж не отображать.
- Добавить короткую легенду под заголовком; она поясняет формат без повторения длинной подписи в каждом дне.
- Для загрузки и ошибки оставить текущий маркер состояния, а подпись «N работ» показывать только при известном количестве.
- Подогнать размер и отступы бейджа для мобильной сетки, где ширина колонки ограничена.

## Risks / Trade-offs

- Подпись занимает дополнительное место → использовать компактный бейдж и проверить существующие мобильные размеры ячеек.
- Большие числа и русская форма слова могут не помещаться → бейджу разрешить перенос текста, сохранив точное значение.
