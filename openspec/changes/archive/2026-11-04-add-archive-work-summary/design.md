## Context

Архив уже получает `description`, `instruction_url`, `criticality` и `psi_status`. Раскрытая строка содержит лениво загружаемый timeline. Мотивация описана в proposal.md.

## Goals / Non-Goals

**Goals:** сделать сведения доступными без открытия дополнительной карточки, сохранить ограничение ширины раскрытой строки и существующую загрузку назначений.

**Non-Goals:** редактирование архивных работ, новые поля, изменение API, миграции БД.

## Decisions

- В колонке названия переиспользовать `TaskInstructionLink`: он уже открывает инструкцию в новой вкладке и останавливает всплытие событий. Отдельная колонка потребовала бы дополнительной ширины таблицы; вывод ссылки только при раскрытии затруднил бы быстрый доступ.
- Добавить перед timeline компактный read-only-блок с описанием и существующими подписями критичности и ПСИ. Использовать поля строки без нового запроса карточки. Сохранить ленивый запрос назначений.
- Для описания использовать `linkify`, сохранение переносов строк, перенос длинных слов и вертикальную прокрутку при высоте свыше 200 px, как в карточке работы. Пустое описание обозначать «—», ссылку при пустом URL скрывать.
- Покрыть поведение тестами `TaskArchiveModal` на Vitest + RTL, проверить layout через Python + Playwright с реальной авторизацией на production-backend. Перед UI-тестом сделать SQLite backup через backup API, собрать frontend; после теста остановить запущенный backend и восстановить БД через backup API с checkpoint, если тест менял данные.

## Risks / Trade-offs

- Длинное описание может увеличивать раскрытую строку → ограничить высоту, проверить переносы и отсутствие горизонтального переполнения на широком и узком экране.
- Изменение содержимого строки может нарушить взаимодействия → проверить ссылку без раскрытия строки и сохранность timeline, восстановления, поиска и пагинации.
