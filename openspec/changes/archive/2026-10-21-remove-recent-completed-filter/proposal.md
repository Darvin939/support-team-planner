## Why

Переключатель «Завершённые за 30 дней» дублирует назначение архива: он добавляет недавние завершённые работы в планировщик, хотя теперь для просмотра всей завершённой истории есть отдельный архив. Удаление переключателя и связанного режима упростит планировщик и оставит один понятный способ просмотра завершённых работ.

## What Changes

- Удалить переключатель и связанное состояние из планировщика.
- Удалить из планировщика фильтр статуса работы, который после этого показывал бы только терминальные статусы, отсутствующие в основном списке.
- Удалить параметр режима недавних завершённых из API и DAO основного списка задач; основной список будет содержать только активные работы.
- Удалить и обновить тесты, query keys, хуки и прочие зависимости от этого режима.
- Сохранить архив как отдельный способ просматривать завершённые и отменённые работы.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `task-lifecycle-visibility`: основной список и планировщик больше не включают завершённые работы по отдельному переключателю; терминальная история доступна через архив.

## Impact

- Frontend планировщика: фильтры, запросы, состояние и тесты.
- Backend API/DAO основного списка задач и связанные тесты.
- Спецификация `task-lifecycle-visibility`; архивный API и интерфейс остаются способом просмотра терминальных работ.
