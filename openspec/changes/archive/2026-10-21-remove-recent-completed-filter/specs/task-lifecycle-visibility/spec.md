## ADDED Requirements

### Requirement: Основной список содержит только активные работы
`GET /api/tasks/{team_id}` SHALL возвращать подходящие под остальные фильтры неудалённые активные работы и SHALL исключать работы в терминальных статусах `done` и `cancelled`. Включение терминальных работ через параметр основного списка не поддерживается. Планировщик SHALL предоставлять фильтры по критичности, сегменту, статусу назначения и статусу ПСИ, но SHALL NOT предоставлять отдельный фильтр статуса работы.

#### Scenario: Запрошен основной список
- **WHEN** клиент запрашивает список задач команды с любыми фильтрами, поиском и пагинацией
- **THEN** API возвращает только подходящие активные работы, а `total` вычисляется по той же выборке

#### Scenario: В планировщике нет фильтра статуса работы
- **WHEN** пользователь открывает фильтры планировщика
- **THEN** интерфейс не предлагает выбирать статусы `done` или `cancelled` для основного списка

#### Scenario: В планировщике нет переключателя завершённых работ
- **WHEN** пользователь открывает планировщик
- **THEN** интерфейс не предлагает включить недавние завершённые работы в основной список

### Requirement: Пользователь просматривает терминальную историю через архив
Терминальные работы SHALL просматриваться через отдельный интерфейс архива выбранной команды с поиском, фильтром по дате завершения и пагинацией.

#### Scenario: Пользователь открывает архив
- **WHEN** пользователь открывает архив выбранной команды
- **THEN** интерфейс показывает только завершённые и отменённые работы и позволяет искать их и ограничивать периодом завершения

#### Scenario: Цвета статусов согласованы с модалкой работы
- **WHEN** архив отображает работу в статусе `done` или `cancelled`
- **THEN** подпись статуса оформлена общей функцией `tintedStyle`: цветом success для `done` и error для `cancelled`, как в модалке работы

## REMOVED Requirements

### Requirement: Основной список ограничивает завершённые работы недавним периодом
**Reason**: Переключатель недавних завершённых удаляется; основной список теперь всегда содержит только активные работы.
**Migration**: Для просмотра завершённых и отменённых работ используйте архив команды.

### Requirement: Пользователь может просматривать недавние завершённые и полный архив
**Reason**: Эта формулировка объединяла удаляемое включение недавних завершённых в планировщик с отдельным архивом.
**Migration**: Просматривайте терминальные задачи через отдельный архив; планировщик показывает только активные задачи.
