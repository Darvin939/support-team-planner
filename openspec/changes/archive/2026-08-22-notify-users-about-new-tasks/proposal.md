## Why

Пользователь может иметь доступ ко многим командам и сейчас узнаёт о добавленных работах только при последовательном просмотре их планировщиков. Нужен персональный, ограниченный по объёму обзор новых работ по всем доступным командам, который не блокирует вход и не повторяет уже просмотренные события.

## What Changes

- Добавить персональное состояние просмотра новых работ и определять новизну относительно подтверждённой пользователем контрольной точки.
- Возвращать точное количество и ограниченное preview новых доступных работ, сгруппированное в интерфейсе по командам.
- Расширить глобальный центр уведомлений отдельным разделом новых работ, сохранив уведомления о просроченных назначениях.
- Ограничить обе вкладки центра пятью элементами одинаковой ширины и вынести полные пагинируемые списки новых работ и просроченных назначений в Drawer.
- При первом открытии планировщика в пользовательской сессии показывать неблокирующий обзор, если есть новые работы.
- Обеспечить переход из уведомления в нужную команду и к конкретной работе, а также явное действие «Отметить просмотренными».
- Не уведомлять автора о созданной им работе; исключать удалённые и недоступные пользователю работы.

## Capabilities

### New Capabilities

- `new-task-notifications`: Персональное определение, ограниченная загрузка, группированное отображение и подтверждение просмотра новых работ по всем доступным командам.

### Modified Capabilities

- `overdue-assignment-notifications`: Существующий popover просроченных назначений становится общим центром уведомлений и сохраняет прежние счётчик, preview и навигацию в отдельном разделе.

## Impact

- SQLite-схема и миграции: состояние просмотра новых работ пользователем и необходимые индексы.
- Backend DAO/API: выборка с учётом доступа, автора, удаления, пагинации, общего количества и безопасной контрольной точки.
- Frontend React/Ant Design: общий центр уведомлений со стабильной геометрией, обзор при входе, два пагинируемых Drawer и навигация к работе или назначению.
- Контракты API, модели и query cache.
- Backend-тесты, Vitest + React Testing Library для поведения компонентов и production UI-сценарий через Python + Playwright.
