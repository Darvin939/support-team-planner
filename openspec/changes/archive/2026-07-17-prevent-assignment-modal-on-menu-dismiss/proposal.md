## Why

Клик вне открытого контекстного меню таблицы планирования одновременно закрывает `Dropdown` и запускает действие элемента под курсором. Из-за этого попытка лишь скрыть меню может неожиданно открыть модальное окно работы или назначения.

## What Changes

- Любой первый клик вне открытого контекстного `Dropdown` таблицы только закрывает меню.
- Поддерживаются контекстные меню календарного назначения и ячейки «Работа».
- Действие элемента под курсором, включая открытие модального окна, выполняется только следующим отдельным кликом.
- Выбор пункта внутри самого меню сохраняет текущее поведение.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `planning-table-structure`: вводится общее правило поглощения внешнего клика для всех контекстных `Dropdown` таблицы.

## Impact

Затронуты frontend-обработчики обоих `Dropdown` и кликов по интерактивным ячейкам в `usePlanningColumns.tsx`. API и база данных не меняются.
