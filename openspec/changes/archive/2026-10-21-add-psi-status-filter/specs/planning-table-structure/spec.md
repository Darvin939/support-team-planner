## ADDED Requirements

### Requirement: Планировщик фильтрует работы по статусу ПСИ
Карточка фильтров планировщика SHALL предоставлять множественный фильтр статуса ПСИ со значениями `not_required`, `required` и `passed`. При выборе одного или нескольких значений список работ SHALL включать только работы с выбранным статусом ПСИ. При пустом выборе фильтр SHALL пропускать работы с любым статусом.

#### Scenario: Выбор статуса ПСИ
- **WHEN** пользователь выбирает один или несколько статусов ПСИ
- **THEN** в таблице планирования остаются только работы, чей статус ПСИ входит в выбранные значения

#### Scenario: Фильтр ПСИ не задан
- **WHEN** пользователь не выбрал значения фильтра ПСИ или очистил выбор
- **THEN** работы не исключаются по статусу ПСИ

#### Scenario: Доступны все статусы ПСИ
- **WHEN** пользователь открывает варианты фильтра ПСИ
- **THEN** доступны варианты из централизованного списка статусов ПСИ: «Не требуется», «Требуется» и «Пройдено»

#### Scenario: Изменение фильтра ПСИ обновляет представление планировщика
- **WHEN** пользователь меняет выбранные статусы ПСИ
- **THEN** планировщик обновляет отфильтрованный список работ и применяет стандартное центрирование таблицы на текущей дате
