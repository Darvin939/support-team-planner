## Why

Планировщик уже показывает статус ПСИ у каждой работы, но не позволяет отобрать работы по этому статусу. Фильтр поможет быстро находить работы, для которых ПСИ требуется, уже пройдено или не требуется.

## What Changes

- Добавить в карточку фильтров планирования множественный фильтр по статусу ПСИ.
- Применять выбранные статусы к отображаемым работам; при пустом выборе показывать работы с любым статусом ПСИ.

### New Capabilities

### Modified Capabilities
- `planning-table-structure`: планировщик предоставляет фильтр работ по статусу ПСИ.

## Impact

- Frontend: `PlanningFiltersCard`, `usePlanningFilters` и `PlanningPage`.
- API и база данных не меняются: `psi_status` уже входит в данные работы.
- Обновляется спецификация поведения фильтров планировщика.
