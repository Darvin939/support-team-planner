## Why

В истории завершённой работы сейчас невозможно понять, в какие даты и какие блоки были назначены. Архив также показывает только плоский список работ без контекста назначений, поэтому нужно дать пользователю компактную временную раскладку без лишних комментариев и исполнителей.

## What Changes

- В карточке завершённой работы добавить видимую по умолчанию секцию с таблицей назначений.
- Строить непрерывный диапазон от самой ранней до самой поздней даты назначения.
- Показывать в таблице только имя блока и статус назначения; пустые даты оставлять видимыми.
- Для нескольких блоков в одной дате показывать отдельные компактные бейджи.
- В архиве добавить раскрытие строки по клику и lazy-загрузку той же таблицы.
- Для работ без назначений показывать состояние «Назначений нет».
- Историю изменений работы оставить скрытой по умолчанию; существующий `successful-history` для буфера обмена не изменять.
- Добавить компактный endpoint для чтения назначений одной работы с проверкой доступа и кэшированием на frontend.

## Impact

Затрагиваются FastAPI endpoint и SQL-запрос назначений, типы и query keys frontend, карточка работы, `TaskArchiveModal`, переиспользуемый компонент временной таблицы и тесты. Изменения не затрагивают создание/редактирование назначений и endpoint `successful-history`.
