## Why

При ручном планировании коллегам нужно видеть порядок блоков сохранённого шаблона раскатки, не переходя в настройки. Компактная легенда поможет сверяться с последовательностью и интервалами прямо в планировании.

## What Changes

- Добавить Popover по нажатию на значок ⓘ рядом с названием работы в таблице планирования и рядом с полем «Блок» в окне ручного назначения.
- Показывать название шаблона и блоки по возрастанию сдвига, объединяя одинаковые сдвиги в один этап и перечисляя его блоки через запятую.
- Подписывать этапы «День 0», «+1 день» и т. п.; пояснять, что сдвиги считаются относительно начала раскатки.
- Предусмотреть загрузку, ошибку и отсутствие доступного шаблона. Легенда информационная: без прогресса, расчёта следующего блока и ограничения ручного выбора.

## Capabilities

### New Capabilities

- `rollout-legend`: доступная с компьютера и телефона всплывающая легенда сохранённого шаблона работы.

### Modified Capabilities

Нет.

## Impact

Frontend планирования: таблица работ, AssignmentModal, общий компонент легенды и использование существующей загрузки шаблонов команды. Backend, формат назначений и правила планирования не меняются. Проверки: Vitest + React Testing Library и production UI через Python + Playwright.
