## Context

Работа хранит completion_template_id. Шаблоны команды доступны через useTeamTemplates, содержат блоки с shift_days. AssignmentModal уже загружает шаблоны для автоназначения. Причина изменения описана в proposal.md.

## Goals / Non-Goals

**Goals:** единое отображение сохранённого шаблона в двух точках интерфейса, без запросов на каждую строку таблицы.

**Non-Goals:** вычисление прогресса, следующего блока, реальных дат и изменение правил ручного или автоматического назначения.

## Decisions

- Общий компонент легенды на Ant Design Popover с trigger="click" и кнопкой ⓘ с доступным названием «Схема раскатки: <название работы>». Клик подходит для телефона; кнопка поддерживает клавиатуру. Наведение как единственный способ открытия не подходит для touch.
- В таблице кнопка располагается рядом с названием работы, в ручном назначении — рядом с подписью поля «Блок». Событие кнопки не должно открывать редактирование работы или назначение через обработчик строки. Легенда доступна и при просмотре без права редактирования.
- Загружать шаблоны один раз для команды через существующий query/cache и передавать состояние в общий компонент. В AssignmentModal переиспользовать существующий запрос. Не добавлять запрос на каждую строку и новый backend API.
- Выбирать только сохранённый completion_template_id с проверкой сегмента. Не подставлять первый шаблон. Для загрузки, ошибки, отсутствующей ссылки, недоступного шаблона и пустого списка блоков показывать понятный текст.
- Группировать копию блоков по shift_days, сортировать этапы по числовому сдвигу, внутри этапа — по названию. Сдвиг 0 обозначать «День 0», остальные форматировать с корректным знаком и русским склонением слова «день». Не мутировать query-данные.
- Внизу показать «Сдвиги относительно начала раскатки» и пояснение «Даты при ручном планировании выбираются отдельно»: значения шаблона не являются вычисленными датами с учётом фризов.
- Ограничить ширину popover шириной viewport с отступами; длинные названия переносить, длинное содержимое прокручивать внутри всплывашки.
- По результатам mobile-проверки ограничить высоту содержимого 40dvh и добавить закреплённую кнопку закрытия внутри легенды: всплывашка может перекрыть исходный значок при длинном шаблоне. Escape закрывает легенду как с кнопки открытия, так и из её содержимого.
- Блоки одного этапа перечислять через запятую с переносом длинного текста по запросу пользователя.

## Risks / Trade-offs

- [Значок внутри кликабельной строки запускает другое действие] → остановить всплытие и проверить component-тестом.
- [Большой шаблон выходит за экран] → перенос текста, ограниченные ширина/высота и production-проверка на телефоне.
- [Отображение не совпадает с сохранённым шаблоном] → проверять идентификатор/сегмент и показывать отсутствие, без автоматического выбора.

## Migration Plan

Миграция БД и backend не требуются. Собрать frontend и развернуть вместе с приложением. Откат — предыдущая сборка frontend.
