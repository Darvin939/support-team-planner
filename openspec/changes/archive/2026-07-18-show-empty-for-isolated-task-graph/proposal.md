## Why

Граф, открытый для конкретной работы без зависимостей, сейчас показывает одну изолированную ноду. Это создаёт впечатление наличия графа, хотя связей нет.

## What Changes

- При открытии графа конкретной работы без единого ребра будет показан компонент Ant Design `Empty` вместо изолированной ноды.
- Пустое состояние будет сообщать, что у работы нет зависимостей.
- Общий граф команды и граф конкретной работы с хотя бы одним ребром сохранят текущее поведение.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `dependency-graph-node-presentation`: Добавляется требование к пустому состоянию графа конкретной работы без зависимостей.

## Impact

- Frontend: `frontend/src/pages/planning/DependencyGraphModal.tsx`.
- Backend API и модель данных не изменяются.
