## ADDED Requirements

### Requirement: Изолированная работа показывается как пустой граф
Система SHALL показывать компонент `Empty` вместо единственной ноды, если граф открыт для конкретной работы и её связная компонента не содержит рёбер.

#### Scenario: Работа без зависимостей
- **WHEN** пользователь открывает граф конкретной работы, а API возвращает одну ноду и ноль рёбер
- **THEN** система показывает `Empty` с сообщением «У работы нет зависимостей» и не показывает ноду

#### Scenario: Работа с зависимостями
- **WHEN** пользователь открывает граф конкретной работы, а её связная компонента содержит хотя бы одно ребро
- **THEN** система показывает граф с его нодами и рёбрами

#### Scenario: Общий граф команды
- **WHEN** пользователь открывает общий граф без `task_id`
- **THEN** критерий пустого состояния по-прежнему основан на отсутствии нод
