## ADDED Requirements

### Requirement: Назначение можно отменить отдельным статусом
Система SHALL поддерживать для назначения статус `cancelled` и показывать его пользователю как «Отменено».

#### Scenario: Выбор отмены в форме
- **WHEN** редактор открывает список статусов в форме назначения
- **THEN** в списке доступен вариант «Отменено» со значением `cancelled`

#### Scenario: Быстрая смена статуса
- **WHEN** редактор открывает контекстное меню назначения с другим статусом
- **THEN** в группе статусов доступено действие «Отменено»

#### Scenario: Отображение отменённого назначения
- **WHEN** API возвращает назначение со статусом `cancelled`
- **THEN** таблица планирования и история изменений показывают метку «Отменено»

#### Scenario: Отмена не считается активным назначением
- **WHEN** назначение имеет статус `cancelled`
- **THEN** оно не входит в выборку и счётчики активных назначений
