## ADDED Requirements

### Requirement: Короткие параметры работы объединены в компактные группы
Форма создания и редактирования работы SHALL визуально выделять две компактные группы без заголовков: критичность и требование ПСИ, затем сегмент и шаблон раскатки. На desktop поля внутри каждой группы SHALL располагаться в две колонки, checkbox ПСИ SHALL выравниваться по контролу критичности. На мобильном поля SHALL складываться в одну колонку в порядке критичность, ПСИ, сегмент, шаблон. Группировка MUST сохранять существующие правила валидации и блокировки полей и MUST не добавлять отдельные строки заголовков.

#### Scenario: Desktop-группировка
- **WHEN** пользователь открывает форму работы на desktop viewport
- **THEN** он видит две компактные группы: критичность рядом с ПСИ, сегмент рядом с шаблоном, без дополнительных заголовков

#### Scenario: Мобильная группировка
- **WHEN** форма работы открыта на узком экране
- **THEN** обе группы помещаются в ширину формы, поля внутри них расположены вертикально и горизонтальное переполнение отсутствует

#### Scenario: Работа с назначениями
- **WHEN** пользователь открывает работу с неудалёнными назначениями
- **THEN** группировка не изменяет блокировку сегмента/шаблона и отдельное правило доступности ПСИ

### Requirement: Повторное открытие формы сбрасывает ошибки валидации
При каждом открытии формы работы система SHALL очищать ошибки, красную подсветку и состояние взаимодействия предыдущего открытия перед заполнением актуальными значениями. Повторная отправка незаполненной формы MUST заново показывать ошибки обязательных полей.

#### Scenario: Повторное создание после ошибок пустой формы
- **WHEN** пользователь отправляет пустую форму создания, закрывает её и открывает снова
- **THEN** форма снова пуста, красная подсветка и сообщения прежней валидации отсутствуют до новой проверки

#### Scenario: Валидация после повторного открытия
- **WHEN** пользователь повторно отправляет незаполненную форму после её открытия заново
- **THEN** ошибки обязательных полей отображаются и работа не сохраняется
