## ADDED Requirements

### Requirement: Связи работ защищают шаблон от удаления и смены сегмента
Система SHALL атомарно отклонять удаление шаблона или изменение его сегмента, если на шаблон ссылается хотя бы одна работа, включая терминальные и мягко удалённые. Название, состав блоков и смещения SHALL оставаться редактируемыми. Ошибка MUST отображаться через существующий механизм сообщений backend и не изменять связанные данные.

#### Scenario: Удаление используемого шаблона
- **WHEN** пользователь удаляет шаблон, на который ссылается работа
- **THEN** API отклоняет операцию с объяснением наличия связей, шаблон и ссылка работы сохраняются

#### Scenario: Перенос используемого шаблона
- **WHEN** пользователь меняет сегмент используемого шаблона вместе с другими его полями
- **THEN** API отклоняет сохранение целиком, форма остаётся открытой и показывает ошибку

#### Scenario: Ссылка терминальной или удалённой работы
- **WHEN** на шаблон ссылается только терминальная либо мягко удалённая работа
- **THEN** удаление и смена сегмента также запрещены

#### Scenario: Правка состава используемого шаблона
- **WHEN** пользователь меняет название, блоки или смещения шаблона, сохраняя сегмент
- **THEN** система разрешает изменение по существующим правилам, а уже созданные назначения автоматически не перепланируются

#### Scenario: Шаблон не используется работами
- **WHEN** ни одна работа не ссылается на шаблон
- **THEN** новая защита не препятствует его удалению или изменению сегмента
