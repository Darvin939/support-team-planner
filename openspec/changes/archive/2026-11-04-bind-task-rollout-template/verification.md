## Production UI

Сценарий `tests/ui_task_rollout.py` запускает production-backend дочерним процессом и авторизуется через настоящую форму администратора. Проверены явный выбор сегмента/шаблона, автоназначение по сохранённому шаблону без Select, блокировка обоих полей, разблокировка после удаления всех назначений, очистка шаблона при смене сегмента, сохранение новой пары и отказы удаления/переноса используемого шаблона в настройках.

На viewport 390×844 проверены границы modal, отсутствие горизонтального переполнения, вертикальный порядок полей и доступность кнопки сохранения при прокрутке. На desktop 1440×1000 проверено выравнивание ПСИ по контролу критичности. Высота формы создания — 752 px вместо прежних 740 px (+12 px), высота каждой группы параметров — 80 px. Снимки визуально проверены.

Регрессионный компонентный тест сначала воспроизвёл три оставшихся ошибочных поля после закрытия/открытия пустой формы. После добавления `form.resetFields()` перед заполнением формы тест проходит. Production UI также подтвердил отсутствие старой красной подсветки при повторном открытии и повторное появление ошибок при новом submit.
