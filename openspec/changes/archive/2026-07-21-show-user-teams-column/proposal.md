## Why

В каталоге пользователей сейчас нельзя увидеть командные ограничения без открытия формы редактирования. При большом числе пользователей это затрудняет аудит доступов, а полный вывод всех команд перегрузил бы таблицу.

## What Changes

- Добавить в таблицу пользователей колонку «Команды» со списком названий явно выбранных команд.
- Для пользователя без явных ограничений показывать понятное обозначение доступа ко всем командам.
- Ограничить число непосредственно отображаемых названий и компактно обозначать оставшееся количество, сохраняя возможность увидеть полный список.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `settings-user-directory`: таблица каталога пользователей дополнительно показывает назначенные команды в компактном виде.

## Impact

- Frontend: `frontend/src/pages/settings/UsersTab.tsx` и, при необходимости, вспомогательный компонент или константа форматирования.
- Данные: используются уже возвращаемые API поля `team_ids` и существующий список команд; backend и схема БД не меняются.
- Тестирование: production-сборка frontend и UI-проверка через Python + Playwright.
