## Context

`UsersTab` уже получает пагинированных пользователей с `team_ids` и полный справочник команд через `useTeams`. Сейчас `team_ids` используется только в форме редактирования. В таблице нужно показать те же данные, не увеличивая объём API и не растягивая строку при доступе к десяткам команд.

## Goals / Non-Goals

**Goals:**

- Сделать явные командные ограничения видимыми непосредственно в таблице.
- Сохранить компактную высоту и ширину строк при большом числе команд.
- Дать возможность прочитать полный список без открытия формы редактирования.
- Однозначно отобразить семантику пустого `team_ids` как доступа ко всем командам.

**Non-Goals:**

- Изменение правил командного доступа, API или схемы БД.
- Редактирование команд непосредственно из ячейки таблицы.
- Поиск и сортировка пользователей по командам.

## Decisions

1. В колонке «Команды» показывать до трёх названий (`N = 3`) как компактные Ant Design `Tag`. Три элемента дают полезный обзор и оставляют таблице разумную ширину. Альтернатива с одной строкой через запятую хуже различает названия и менее удобна для визуального сканирования.
2. При количестве больше трёх добавлять тег `+N`, где число означает количество скрытых команд. На ячейку или тег `+N` добавить `Tooltip` с полным списком названий. Альтернатива «и ещё…» без количества даёт меньше информации; раскрываемая строка усложняет таблицу и меняет её высоту.
3. Пустой `team_ids` показывать отдельным тегом «Все команды», поскольку по действующему контракту пустой список означает отсутствие ограничений. Для администратора это обозначение также корректно отражает эффективный доступ.
4. Идентификаторы сопоставлять с названиями через локальную карту из результата `useTeams`; порядок сохранять в соответствии со справочником команд, а неизвестные идентификаторы не выводить как ложные названия. До загрузки справочника ячейка может показывать нейтральный индикатор загрузки.

## Risks / Trade-offs

- [Risk] Длинные названия могут расширять таблицу даже при лимите в три элемента. → Задать колонке ограниченную ширину и разрешить перенос тегов внутри неё.
- [Risk] Справочник команд загружается отдельно от пользователей, поэтому данные появляются не одновременно. → Использовать существующий query cache и нейтральное состояние до завершения запроса без изменения API.
- [Risk] Скрытый список недоступен на устройствах без hover. → Видимый `+N` всё равно сообщает объём; полный список доступен в существующей форме редактирования администратору.
