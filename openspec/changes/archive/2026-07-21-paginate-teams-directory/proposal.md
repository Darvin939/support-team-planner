## Why

Вкладка «Команды» выводит все команды вертикальным списком карточек без поиска и пагинации. После расширения демо-данных и при реальном росте числа команд такой список становится длинным, медленным для просмотра и неудобным для администрирования.

## What Changes

- Заменить карточки на вкладке «Команды» таблицей Ant Design с колонками названия, разрешённых шаблонов и действий.
- Добавить поиск по названию команды с серверной фильтрацией до пагинации.
- Добавить серверную пагинацию и выбор размера страницы по образцу вкладки пользователей.
- Разместить кнопку добавления и поиск в единой inline-панели на вкладках «Команды» и «Пользователи», сохранив отступ до таблицы.
- Сохранить прежний полный формат `GET /api/teams` без query-параметров для существующих потребителей.
- Сохранить действующие ограничения командного доступа и CRUD-поведение.

## Capabilities

### New Capabilities

- `settings-team-directory`: табличное отображение, поиск, пагинация и совместимость полного списка команд в настройках.

### Modified Capabilities

- `team-access-control`: пагинированный и поисковый список команд учитывает эффективный доступ текущего пользователя до подсчёта и выдачи строк.

## Impact

- Backend: DAO списка команд и `GET /api/teams` получают опциональные `offset`, `limit`, `search`.
- Frontend: `TeamsTab`, `UsersTab`, `useTeams`/новый paginated hook, query keys и существующие компоненты пагинации.
- Совместимость: вызовы `/api/teams` без параметров продолжают получать полный массив.
- Тестирование: backend-тесты фильтрации/пагинации и production UI-тест через Python + Playwright.
