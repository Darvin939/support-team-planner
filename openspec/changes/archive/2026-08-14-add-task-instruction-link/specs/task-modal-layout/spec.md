## ADDED Requirements

### Requirement: Модалка выделяет ссылку на инструкцию из описания

Frontend SHALL показывать на вкладке `Основное` отдельное полноширинное поле `Ссылка на инструкцию`, SHALL включать его в единую операцию сохранения работы и MUST отдельно сохранять поддержку ссылок внутри поля `Описание`.

#### Scenario: Редактирование работы со ссылкой на инструкцию
- **WHEN** пользователь открывает активную работу с заполненым `instruction_url`
- **THEN** вкладка `Основное` показывает ссылку в отдельном поле после описания, а общая кнопка сохраняет оба значения независимо

#### Scenario: Frontend-валидация ссылки
- **WHEN** пользователь вводит в отдельное поле непустой невалидный HTTP(S)-URL и нажимает кнопку сохранения
- **THEN** frontend показывает ошибку у поля и не отправляет save-запрос

#### Scenario: Read-only-представление
- **WHEN** пользователь открывает терминальную работу
- **THEN** модалка показывает `instruction_url` как кликабельную ссылку, открываемую в новой вкладке с `noopener noreferrer`, либо `—` для пустого значения

#### Scenario: Ссыли в описании сохраняются
- **WHEN** в `description` работы есть HTTP(S)-адрес независимо от значения `instruction_url`
- **THEN** read-only-вывод описания продолжает преобразовывать этот адрес в кликабельную ссылку

### Requirement: Планировщик показывает ссылку на инструкцию

Frontend SHALL показывать в колонке `Работа` компактную ссылку `Инструкция ↗` для работы с непустым `instruction_url`, MUST открывать её в новой вкладке с `noopener noreferrer` и MUST NOT запускать по этому клику действия строки работы.

#### Scenario: Работа со ссылкой в планировщике
- **WHEN** планировщик отображает работу с непустым `instruction_url`
- **THEN** под метаинформацией работы видна ссылка `Инструкция ↗`

#### Scenario: Работа без ссылки
- **WHEN** планировщик отображает работу с `instruction_url = NULL`
- **THEN** ссылка `Инструкция ↗` для этой работы не показана

#### Scenario: Клик по ссылке
- **WHEN** пользователь активирует `Инструкция ↗`
- **THEN** браузер открывает `instruction_url` в новой вкладке с `noopener noreferrer`, а модалка и контекстное меню работы не открываются
