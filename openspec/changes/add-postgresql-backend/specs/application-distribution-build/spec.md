## MODIFIED Requirements

### Requirement: Полный минимальный состав
Скрипт MUST включать Python runtime-исходники обоих backend, их миграции, CLI переноса данных, `requirements.txt`, production launch-скрипты, `frontend/dist`, runtime-файл frontend-данных и инструкции запуска и переноса. Относительные пути MUST соответствовать ожидаемым приложением; инструкции MUST поставляться без секретов подключения.

#### Scenario: Проверка состава результата
- **WHEN** сборка дистрибутива завершена успешно
- **THEN** приложение может импортироваться и находить production frontend и файл переходов статусов из выходного каталога

#### Scenario: Подготовка PostgreSQL из дистрибутива
- **WHEN** оператор установил зависимости дистрибутива и задал подключение PostgreSQL
- **THEN** из выходного каталога доступны проверка схемы, pre-deploy миграции и импорт SQLite

### Requirement: Исключение локальных и development-данных
Скрипт MUST формировать дистрибутив по явному списку runtime-файлов и MUST NOT включать локальную SQLite БД, WAL/SHM, резервные копии, PostgreSQL dumps, отчёты с данными подключения, `.env`, логи, кэши, virtualenv, `node_modules`, frontend-исходники кроме обязательного runtime-файла, тесты и OpenSpec-артефакты.

#### Scenario: Локальные файлы присутствуют в рабочем дереве
- **WHEN** в репозитории существуют БД, секреты, backup, dumps, кэши или другие исключённые development-файлы
- **THEN** они отсутствуют в готовом дистрибутиве

### Requirement: Документированный запуск
Документация MUST описывать сборку и состав дистрибутива, зависимости, запуск двух независимых экземпляров и выбор СУБД. Для PostgreSQL MUST описываться подготовка схемы, права runtime без DDL, импорт, явная замена тестовых данных, backup/restore и граница финального переключения. Запуск SQLite без PostgreSQL URL MUST оставаться доступным.

#### Scenario: Подготовка установки по документации
- **WHEN** оператор следует README на машине с Python
- **THEN** он может установить зависимости и запустить приложение из сформированного каталога

#### Scenario: PostgreSQL предоставлен инфраструктурой
- **WHEN** оператор располагает готовой PostgreSQL 15 БД и соответствующими учётными записями
- **THEN** инструкции позволяют подготовить схему и подключить приложение без установки серверной СУБД самим приложением

#### Scenario: Два экземпляра работают параллельно
- **WHEN** оператор разворачивает тестовый PostgreSQL рядом с рабочим SQLite
- **THEN** инструкции задают независимые настройки, рабочие каталоги, адреса доступа и сессии и явно определяют SQLite как рабочий источник до переключения

#### Scenario: Повторный перенос после тестирования
- **WHEN** оператор следует инструкции обновления тестового PostgreSQL
- **THEN** он останавливает тестовый экземпляр и его автоперезапуск, получает новый SQLite-снимок и использует явную замену со сверкой; для финального переноса дополнительно останавливает рабочую запись SQLite
