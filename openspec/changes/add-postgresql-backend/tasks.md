После неё использовать восстановление PostgreSQL без замены из устаревшего SQLite; сохранить резервные копии до приёмки.

## Workflow follow-up

- Перед apply, sync, archive и commit получать отдельные разрешения согласно AGENTS.md; согласование этих артефактов не заменяет будущие разрешения этапов.
- После выполнения обязательных задач и приёмки запросить sync основных спецификаций, затем отдельно archive; незавершённые проверки/переключение не отмечать выполненными ради архивации.
- Commit создавать только после отдельного разрешения пользователя; не публиковать секреты, snapshots, dump и приватные отчёты переноса.

## Состояние проверки реализации

Код подготовлен и проверен на SQLite; подробности и ограничения: [verification.md](verification.md). PostgreSQL-проверки, репетиция и рабочее переключение отложены по решению пользователя. Непроверенные PostgreSQL-критерии не отмечаются выполненными.
