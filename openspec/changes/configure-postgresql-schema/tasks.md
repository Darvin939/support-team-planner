## Workflow follow-up

- Перед реализацией получить разрешение на OpenSpec apply по AGENTS.md.
- После реализации и проверки отдельно согласовать sync основной спецификации `postgresql-schema-configuration`.
- Отдельно согласовать archive завершённого изменения; невыполненную PostgreSQL-приёмку явно отразить перед решением об архивировании.
- Commit выполнять только после отдельного разрешения; фактический перенос пользовательской БД и переключение эксплуатации не входят в реализацию параметра.
